## 代入问题：评估垃圾邮件过滤器

你有一个模型，每封邮件被标记为 `spam` 或 `not-spam`。
你需要知道的不仅是“有多少封邮件是对的”，还要知道“错在哪里”。

这个固定数据集有 12 封邮件：

<ConfusionMatrixScenarioFigure lang="zh" scenarioId="hook-grid" />

## 第一个朴素想法

最直接想到的分数是总正确率：

`正确 / 总数`。

对这 12 封邮件是 `7 / 12 = 58.3%`。

但这会把不同错误混在一起：

<ConfusionMatrixScenarioFigure lang="zh" scenarioId="naive-tally" />

## 错误为什么不一样痛

`e3` 和 `e4` 都是错，但语义完全不同：

- `e3`：真实不是垃圾邮件却被拦截（误报），
- `e4`：真实是垃圾邮件却放过了（漏报）。

<ConfusionMatrixScenarioFigure lang="zh" scenarioId="e3-e4-mistake-contrast" />

## 核心发明

把判断拆成两个是/否问题：

- 真实标签 `actual` 是不是正类；
- 预测标签 `predicted` 是不是正类。

这就得到四个格子。

<ConfusionMatrixScenarioFigure lang="zh" scenarioId="quadrant-seed" />

## 交互演示

逐步处理 12 条邮件，观察每一步只给一个格子加一。

<ConfusionMatrixDemo client:load lang="zh" />

这个示例是确定性的：同一封邮件始终带来同一步迁移。

## 正式定义

设 `y` 是真实标签，`\hat{y}` 是模型预测。
在本节点中，正类明确声明为：

`1 = spam`，`0 = not spam`。

以下用行列法定义矩阵（行是实际，列是预测）：

$$
\begin{array}{c|cc}
& \hat{y}=1 & \hat{y}=0 \\
\hline
y=1 & TP & FN \\
y=0 & FP & TN
\end{array}
$$

`1` 表示“正类”这一约定，而不是“更正确”。

`TP`、`FP`、`TN`、`FN` 是这四个格子的计数。

<ConfusionMatrixScenarioFigure lang="zh" scenarioId="orientation" />

不变量为：

$$
TP + FP + TN + FN = n.
$$

`n` 是已评估邮件数。

共享的数据给出：

- `TP = 3`
- `FP = 2`
- `TN = 4`
- `FN = 3`
- `correct = TP + TN = 7`
- `wrong = FP + FN = 5`
- `total = 12`

## 实现草图

每条邮件只会进入一个格子并更新一个计数器：

```ts
if (actual === positiveLabel && predicted === positiveLabel) {
  tp += 1;
} else if (actual !== positiveLabel && predicted === positiveLabel) {
  fp += 1;
} else if (actual !== positiveLabel && predicted !== positiveLabel) {
  tn += 1;
} else {
  fn += 1;
}
```

<ConfusionMatrixScenarioFigure lang="zh" scenarioId="branch-table" />

## 正确性直觉

两个布尔问题是穷尽且互斥的。

对同一个正类定义，每条邮件只属于这四种组合之一：

- 实际正类且预测正类
- 实际负类且预测正类
- 实际负类且预测负类
- 实际正类且预测负类

因此每条邮件只进入一个格子。处理 9 条后是：

TP = 2，FP = 2，TN = 3，FN = 2，总计 9。

到全部 12 条结束后是：

TP = 3，FP = 2，TN = 4，FN = 3，总计 12。

<ConfusionMatrixScenarioFigure lang="zh" scenarioId="invariant" />

可写成前缀不变量：

$$
TP + FP + TN + FN = \text{已处理样本数}
$$

到末尾时，已处理样本数即 12。

## 复杂度

这类扫描是单次遍历：

$$
\text{time} = O(n), \qquad \text{extra space} = O(1).
$$

每封邮件做固定次数比较和一次计数器更新。

## 常见误解

<ConfusionMatrixScenarioFigure lang="zh" scenarioId="common-confusions" />

再看一个“换正类”练习，保持真实/预测标签不变，改 `positiveLabel = "not-spam"`：

- `TP = 4`
- `FP = 3`
- `TN = 3`
- `FN = 2`

这不改变预测本身，只改变了我们问“正类是什么”的问题。
