# Reference Mockup Notes

The generated multi-page mockup should be treated as a moodboard, not a pixel-perfect spec.

Preserve these directions:
- bright but calm light theme
- blue/orange/green brand language
- graph-paper background in hero and lab contexts
- knowledge graph page with filters and concept preview
- concept page with sidebar, progress, callouts, and lab panel
- bilingual English/Chinese page parity
- design-system page showing tokens and reusable components

Do not copy these problems if present:
- overly tiny text
- any illegible labels
- inconsistent spacing
- UI elements that look too dense
- decorative details that would be expensive to maintain
