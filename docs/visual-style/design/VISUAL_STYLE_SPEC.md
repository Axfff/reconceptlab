# Visual Style Spec: Explorable Lab Notebook

## One-sentence identity

ReConcept Lab is an explorable lab notebook for computer science: clean like documentation, visual like a graph, interactive like a simulator, and warm like a learning journal.

## Core metaphor

```text
Lab        -> experiment, sandbox, evidence, testing
Graph      -> connected knowledge, dependencies, paths
Notebook   -> progressive explanation, sketches, learning journey
```

## Desired feeling

The interface should feel serious enough for CS learning, but imaginative enough to make concepts feel alive.

Keywords:

```text
curious
precise
visual
progressive
calm
interactive
scientific
warm-tech
```

## Main visual devices

1. Subtle graph-paper backgrounds in hero and lab sections.
2. Rounded cards with light borders and soft shadows.
3. Knowledge-node capsules and graph-node dots.
4. Blue/orange/green state language.
5. Notebook-like annotations used sparingly.
6. Interactive lab panels with visible trace/state areas.
7. Bilingual typography that works for English and Simplified Chinese.

## Do not do

- Do not make every section glow.
- Do not use pure black dark mode.
- Do not rely on large AI-generated decorative backgrounds.
- Do not make the UI look like a crypto dashboard.
- Do not use low-contrast pastel text.
- Do not hide algorithm state changes behind fast animations.
